# Лабораторна: позиційне кодування

Токенізатор перетворює текст на послідовність id, а embedding-таблиця — кожен
id на вектор. Спочатку реалізуємо embedding-шар: вибір рядків таблиці за id
токенів. Потім використаємо його вихід із позиційними кодуваннями й
дослідимо, як трансформер отримує інформацію
про порядок токенів: додавання позиційних векторів, фіксовані синусоїдальні
кодування, навчену таблицю, Fourier features та RoPE. У розділі 4.1
використаємо PyTorch: допишемо `forward` для embedding-шару з навчуваними
позиціями або Fourier-частотою, запустимо готовий цикл навчання та
повторно використаємо навчені шари для нової послідовності.

## Для студентів

Відкрийте [positional_encoding.ipynb](positional_encoding.ipynb) у Jupyter або
VS Code і виконуйте комірки по черзі. Заповніть функції з `...` так, щоб
перевірки під ними проходили. Потрібен Python 3.10 або новіший. Для
розділу 4.1 встановіть PyTorch у тому самому середовищі:

```bash
python3 -m pip install torch
```

У ноутбуці можна виконати `%pip install torch` в окремій комірці. Решта
вправ використовує стандартну бібліотеку Python.

Можна працювати і без ноутбука: редагуйте
[positional_encoding.py](positional_encoding.py) та запускайте
`python3 positional_encoding.py`. Перший незавершений розділ зупинить запуск;
після його реалізації переходьте до наступного.

## Для оновлення ноутбука

Python-файл є джерелом ноутбука. Після редагування виконайте:

```bash
make notebook
```

`make check` перевіряє синтаксис Python-файла та конвертера. Воно не запускає
студентські завдання, оскільки їхні реалізації навмисно залишено порожніми.
